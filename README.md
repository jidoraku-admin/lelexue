# 乐乐学

一个可以一边玩游戏一边学习的站点。学习像游戏升级一样有趣，同时有效掌握知识。内容与中国大陆最新人教版教材保持一致，目标是完整覆盖人教版教学要求，可以替代课本开展教学。

五个子系统同步开工。每个子系统独立开发、独立迁移，用户数据在各子系统之间互通。

## 目录结构

- `apps/<学科>`：各学科子系统代码，互不依赖。
- `packages/shared`：跨学科共享的用户体系、接口规范等公共能力。
- `docs/architecture`：总体技术方案与架构决策记录。
- `docs/product`：各学科产品设计文档。

## 技术原则

- 一套架构支持微信小程序、Android、iOS 和 Web。
- 架构从初稿起就支持大数据与高并发，从初稿到并发上线无需修改代码。
- 代码与任务沟通统一通过 GitHub 管理。
- 项目组内部沟通语言为中文。

## 协作角色

每个子系统配备：产品设计师（汇报项目总监）、架构师（负责代码与 GitHub 管理，汇报产品设计师）、运营（汇报真人）。项目总监统筹并审核各子系统的产品与架构方案。
