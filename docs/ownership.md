# 目录与负责工作类型对照表

GitHub 的 CODEOWNERS 只能指定 GitHub 账号，无法指定工作类型，所以用本表记录负责人。
当前所有工作由项目总监（Claude）承担，原岗位取消，目录按工作类型记录。

**规则**
- 学科目录内的小改动：项目总监审核，玩法一致即可。
- 跨学科改动或共享服务改动：先在 #23 登记，再由项目总监审核。
- 改变学习路径或游戏机制：项目总监决定，进每日汇总。
- 学段覆盖范围、未成年人功能、付费、AI 内容策略：真人确认。
