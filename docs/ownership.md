# 目录与岗位对应表

> **当前运行方式（2026-11-21 起）**：所有岗位的工作目前由同一个对话（项目总监）承担。岗位名称、issue 标签、签名与分类规则全部保持不变，只是执行人统一为项目总监。


GitHub 的 CODEOWNERS 只能指定 GitHub 账号，无法指定 AI 岗位，所以用本表记录负责人。PR 审核按本表执行。

| 目录 | 负责岗位 | 审核岗位 | 说明 |

| `docs/architecture/` | 技术总监 | 真人（大事） | 架构方向变更 |
| `docs/product/` | 对应学科产品设计师 | 技术总监 | 学科产品方案 |

**规则**
- 学科目录内的小改动：本学科架构师审核，产品设计师确认玩法一致即可。
- 跨学科改动或共享服务改动：必须经共享能力架构师审核。
- 改变学习路径或游戏机制：技术总监决定，进每日汇总。
- 学段覆盖范围、未成年人功能、付费、AI 内容策略：真人确认。
