## 5. 上线门槛（全部满足才能对外开放）
1. 备案已完成，域名与服务器已绑定；
2. 小程序认证已通过；
3. 等保定级已确认，测评已完成或已预约；
4. 法务已复核未成年人规则与个人信息保护，隐私政策已发布；
5. 真人确认定稿与验收（stage:acceptance 通过）；
6. 覆盖率审计通过（单元的词汇、句型、语法、听说项目全部映射到关卡）。

## 6. 风险与应对
| 风险 | 应对 |
| --- | --- |
| 备案周期长，上线推迟 | 最早启动备案，验证与开发并行进行 |
