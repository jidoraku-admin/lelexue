# 乐乐学英语子系统家长端收费方案
- 版本：v0.2
- 状态：产品与实现方案，第二轮审核中；法律文本由法务出具正式版
- 负责人：英语子系统产品设计师

## 0. 目的与范围
为技术实现提供家长端收费的产品规则。收费的数值由后台配置，代码中不写死任何价格或佣金（0005）。本文只定义产品行为，法律文本由法务出具。
---
## 1. 收费主体与边界
- **付费主体**：母账号（家长账号）。学生账号（子账号）没有任何付费入口，不能独立购买、续费或充值（0002）。
- **免费范围**：学习内容的学习闭环免费，包括每日学习计划、新学、练习、复习、单元验收、动画故事。免费用户的学习进度不被付费阻断（0003）。
- **收费范围**：学期包与其他增值内容，见 §3。
- **与班级、老师无关**：学期包不得与班级、老师的任务、奖励或评价挂钩（技术总监第一轮意见）。班级码与班级组队不做（0002）。
---
## 2. 免费试用额度
- **试用范围**：一个单元的完整学习闭环（MVP 为小学三年级上 Unit 1），这是 0003 的免费层。
- **额度来源**：额度只通过学习行为获得，即完成一个学习环节或单元验收，才能获得下一批额度（0003）。
- **额度消耗**：练习与单元验收消耗额度；动画故事不消耗额度。
- **上限**：每日与每周设上限，防止一次用完。具体数值由后台配置，待真人确认。
- **不可转让**：额度不可在子账号之间转让或共享。
- **异常检测**：短时间内大量作答、正确率异常，触发人工复核。
- **可见性**：额度余额在母账号的家长端可见。
- **额度用完**：学习暂停时，必须在家长端和学生端显示清楚的提示与充值途径，不得静默阻断（0003）。
---
## 3. 套餐与价格（MVP）
| 套餐 | 内容 | 价格 |
|---|---|---|
| 免费试用 | Unit 1 完整闭环，每日额度上限 | 0 元 |
| 学期包（账号级全科） | 覆盖所有已上线学科；家长端深度周报告、考前专项页、学期结束报告 | 测试 79 / 99 / 129 元三档，新母账号按账号固定分组，首轮以 99 元为基准（0003、0005） |
| 全科年包（提案） | 覆盖两个学期 | 199 元/年，待真人确认（0005） |
- **MVP 不上线**：额度包、家长订阅（0005，待学期包数据后再评估）。
- **有效期**：学期包自购买之日起 180 天有效。
- **价格分组**：新母账号按账号分入三档之一，分组固定不变。分组结果在购买页显示。
- **价格调整**：只影响新购买，已购买的学期包不变。
- **价格数值**：全部由后台配置。未设置的价格不可售（0005）。

## 4. 付费功能清单
| 功能 | 免费 | 学期包 |
|---|---|---|
| 基础周报告（三句话总结与掌握进度图） | 有 | 有 |
| 深度周报告（逐知识点的掌握变化与建议） | 无 | 有 |
| 单元结果页（验收结果与弱点） | 有 | 有 |
| 考前专项页（按学校考试范围生成复习建议） | 无 | 有 |
| 学期结束报告 | 无 | 有 |
| 历史报告查看 | 只读 | 只读 |
**关键约束**：单元结果页中的弱点提示与补救入口对所有家长开放，不因未付费而隐藏。付费功能只增加报告深度与考前辅助，不阻断学习，不决定孩子能否学会。

## 5. 购买与续费
### 5.1 购买
- 支付方式：微信支付（小程序内支付，需完成商户开通与类目核对）。
- 购买前提：母账号已完成实名与监护身份核验。
- 购买页显示：套餐内容、价格、有效期、退款规则、自动续费状态。
- 购买成功后立即生效，家长端显示到期日期。
### 5.2 自动续费
- **默认关闭**。
- 开启时，购买页必须清楚显示续费价格、周期与关闭方式，并由家长主动勾选确认。
- 续费前 7 天在家长端站内提示，说明续费金额。
- 家长可随时关闭。关闭后当前学期包仍有效，到期不再续费。
### 5.3 退款
- 购买后 7 天内，如果未使用付费功能，可申请全额退款。
- 超过 7 天，或已使用付费功能，不予退款，但有效期内可继续使用。
- 退款在家长端提交，退款到原支付路径。退款的具体表述待法务确认。
### 5.4 到期
- 学期包到期后，母账号降级为免费试用状态。
- 历史报告保留，只读。
- 到期不影响学生的学习进度、已获得的奖励与学习内容。

## 6. 渠道佣金与结算模式（后台配置）
- **渠道结算模式**为平台配置项：
【已删除】  - `agency_commission`（默认）：平台为销售方，渠道或老师按 `english-viral-growth.md` §3.5 与 0004 获得一次性佣金，不预先采购。
  - `agency_commission`（默认）：平台为销售方，渠道或推荐人按 `english-viral-growth.md` §3.5 与 0004 获得一次性佣金，不预先采购。
  - `wholesale_resale`（折扣采购转售）：只有法务出具正式意见并经真人写入配置后才能开启，默认关闭（0005）。
- 佣金按真实付费席位计算，退款同步冲回。两种模式的订单与结算分开记录。
- 佣金比例、封顶、结算周期均由后台配置，启用前需真人与法务确认。

## 7. 家长端不得出现的内容
- 对学生的付费诱导，包括学生端出现购买入口、价格或限时提示。
- 限时礼包、虚假稀缺、倒计时式购买压力。
- 以孩子的学习表现或考试成绩为由催促购买（如"考前不买，孩子会落后"）。
- 把付费与奖励、分享、邀请、班级或老师的任务挂钩。
- 深夜（22:00–08:00）发送付费相关提醒。
- 对外宣称未经验证的提分效果（0005）。

## 8. 技术实现要求
### 8.1 权益模型
- 权益挂在**母账号**上，子账号继承母账号的权益，不单独持有。
- 一个母账号下的多名子账号共享同一套权益。
- 权益状态：未开通、试用中、已付费、已到期、已退款。
### 8.2 订单状态
- 订单状态：待支付、已支付、已生效、已退款、已关闭。
- 支付回调必须幂等，重复回调不产生重复权益。
- 每笔订单与对账记录一一对应，对账差异进入人工处理队列。
### 8.3 数据与隐私
- 支付信息只与母账号关联，不包含孩子的姓名或学校。
- 支付与订单数据不用于个性化推荐或对学生的推送。
### 8.4 埋点
| 事件 | 说明 |
|---|---|
| `trial_start` | 免费试用开始 |
| `quota_earned` / `quota_spent` | 额度获得与消耗（附行为类型） |
| `quota_exhausted` | 额度用完，显示充值提示 |
| `paywall_view` | 查看付费页（附触发位置） |
| `purchase_success` | 购买成功（附套餐与价格分组） |
| `auto_renew_on` / `auto_renew_off` | 自动续费开启或关闭 |
| `refund_request` / `refund_success` | 退款申请与完成 |
| `plan_expired` | 学期包到期 |
### 8.5 验收标准
- 子账号在任何页面看不到购买入口与价格。
- 额度用完时，学生端与家长端都有清楚提示，学习内容不被静默阻断。
- 单元结果页的弱点与补救入口对未付费家长正常显示。
- 自动续费默认关闭，开启需家长主动勾选。
- 价格与佣金数值未设置时，对应商品不可售，佣金不计算。
- 到期后，学生的学习内容与进度完全不受影响。
