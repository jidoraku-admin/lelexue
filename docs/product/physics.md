## 1. 定位

面向初二学生的物理学习游戏。玩家扮演「物理探索员」，在「现象观测站」完成观测与模拟实验任务，通过任务升级。知识以现象、规律与测量为核心，不以公式背诵为主。

对外文案不承诺提分效果，效果以对照实验数据为准。

## 2. 游戏循环

### 2.1 玩家的一天（5–10 分钟一轮）

1. 进入当天的观测区地图，看到今天要点亮的 2–3 个关卡。
2. 观看本章的一段原创动画（约 60 秒，可跳过，跳过不影响进度）。
3. 依次完成「概念关 → 观测关 → 应用关」。
4. 获得经验与观测记录，升级后解锁下一个关卡或探索员装备。
5. 当天结束时，系统用「复习卡」提醒最需要复习的 3 个知识点。

### 2.2 章结构（每章一张地图）

- 概念关：讲解与即时小测，覆盖本章各节的核心概念（玩法：配对、选择）。
- 观测关：模拟实验，学生先预测结果，再通过调节条件对照模拟结果（玩法：预测，学科内实现，不占用框架）。
- 应用关：情境小任务，把规律用于生活场景（玩法：选择）。
- 工坊关（仅第二、三、五章第 5 节的跨学科实践）：在模拟中完成设计与检验（玩法：拖拽搭建、排序，依赖框架第二批）。
- 章 Boss：综合挑战，覆盖本章的概念、计算与图像。Boss 为学科内定义，生命值与通过门槛由物理自行设定，不共享（见第 9 节），通过后解锁下一章。
- 复习关：每章结束后自动出现，按间隔安排复习旧内容。

### 2.3 失败与再挑战

- 答错时立即给出一条原理解释，不直接显示答案。
- 关卡失败后可立即再挑战，不扣经验。
- Boss 失败后，系统标出薄弱的知识点，自动安排补救关卡，补救通过后可再次挑战。

### 2.4 进度与奖励

- 经验只来自掌握，不来自时长或关卡次数。同一知识点的经验只在首次达到 2★ 时给予（与共享游戏化规则一致）。
- 掌握度数值沿用英语的起始值，学科自定，可修改（依据 #16 2026-11-22 21:05 JST 项目总监留言）：1★ 识别正确率 ≥80% 且不少于 5 题；2★ 应用正确率 ≥80% 且不少于 5 题；3★ 新语境正确率 ≥80% 且间隔复习通过一次。各知识点的星级目标见第 6.4 节。
- 等级决定可装备的探索员工具与观测区域，不决定能否进入下一章。
- 观测记录：收集的记录与故事章节相连，不设付费加速。
- 进度只由掌握度决定，时长只作推荐，不设强制时长。

## 3. 每个学习环节都是游戏

| 教材环节（类别） | 游戏形式 |
| --- | --- |
| 概念学习 | 观测站讲解：在模拟场景中观察现象，点选关键概念（配对、选择） |
| 实验探究（模拟） | 观测关：先预测，调节条件，再对照模拟结果（学科内预测） |
| 读数与测量 | 仪器关：点选刻度位置，读出数值，错误时给出读数原理 |
| 计算与公式应用 | 速度挑战、密度计算：根据给定条件计算，输入值有范围校验 |
| 图像与数据 | 数据判读：根据路程-时间、温度-时间、质量-体积数据，选择对应的规律 |
| 跨学科实践 | 工坊项目：设计、预测、检验三步（拖拽搭建、排序，第二批） |
| 单元小结 | 章 Boss：综合挑战，决定是否进入补救 |

## 4. 动画故事

每章一条原创主线，角色与世界统一，不沿用教材中的人物与情节。

世界观：一座「现象观测站」，玩家扮演刚被录取的新探索员。观测站的向导是小机器人「灯灯」。每章的观测任务都与一个真实的小故障有关，修好它就推进剧情。

「灯灯」形象草案（美术定稿前的文字描述）：
- 体型：一只约手掌大小的圆形小机器人，身体中央是一块发光的指示灯。
- 特征：头部可以换上不同的透镜，平面镜（第四章）、凸透镜（第五章）等，用来表示当前章节的主题。
- 性格：耐心、爱提问，每次作答错误时先问「你觉得是哪里不一样？」，而不是直接给答案。
- 名字：沿用「灯灯」，与指示灯形象对应。

| 章节 | 章节主题（原创） | 故事线 |
| --- | --- | --- |
| 第一章 机械运动 | 赛道测速 | 观测站的赛道计时器坏了，玩家用刻度尺与停表重新测出赛车的速度。 |
| 第二章 声现象 | 回声山谷 | 山谷里的回声乱了，玩家通过测量与观察，找出声音传播与回声的规律。 |
| 第三章 物态变化 | 雾凇工坊 | 工坊的雾凇需要按时出现，玩家在模拟中调节温度，观察物态变化。 |
| 第四章 光现象 | 镜子迷宫 | 迷宫的光路错了，玩家通过反射与折射的规律重新规划光路。 |
| 第五章 透镜及其应用 | 显微花园 | 花园里的小虫需要被看清，玩家通过模拟透镜成像找到合适的位置。 |
| 第六章 质量与密度 | 宝石称重 | 宝石商人的天平失准，玩家通过称量与体积测量判断宝石的材质。 |

- 动画规格：每章 4–5 段，每段约 60 秒，原创动画，不做需要真人演员或版权素材的内容。
- 章节顺序已与第 6.1 节核对一致。

## 5. 趣味、吸引性与家长价值

- 即时反馈：每次作答都有动画与声音；连续正确获得连击加成（连击只影响视听，不计分，与共享规则一致）。
- 向导陪伴：「灯灯」在关卡中给出提示与鼓励，提示为教学内容的一部分。
- 收集与装备：收集的记录与装备与故事章节相连，不与付费挂钩。
- 节奏：每 5–10 分钟有一个小目标；每章有一个明确的 Boss 挑战。
- 首关成就感：首关（P1）设计为约 8–10 分钟内完成第一次正确读数，并给出「灯灯」的鼓励与音效（见第 7.1 节）。需要试玩验证是否在一分钟内获得第一次成就感。
- 家长价值：与课内同步，每周生成一份「本周观测记录」，列出孩子掌握的知识点与需要复习的内容，便于家长对照课堂学习，不展示与他人的比较。

## 7. 首个切片：第一章「机械运动」

目标：学生完成 4 个观测任务，学会测量长度与时间并读数，理解速度的意义，能判断匀速与变速，并能选择参照物。时长约 4 关，每关 8–12 分钟。

| 编号 | 任务 | 游戏化形式 | 关键知识 | 题型 | 安全提示 |
| --- | --- | --- | --- | --- | --- |
| P1 | 刻度尺与停表读数 | 仪器读数：点选刻度位置 | 分度值、估读、停表读数 | 点选、数值（带单位） | 无 |
| P2 | 测量小车的平均速度 | 速度挑战：设定路程与时间，预测速度（对应第 4 节的斜面实验） | v = s / t；平均速度与瞬时速度的区别 | 数值（带单位）、选择 | 无 |
| P3 | 判断匀速与变速 | 数据判读：根据路程-时间数据，选择匀速或变速的运动 | 相同时间内路程相等为匀速；路程不等为变速 | 选择 | 无 |
| P4 | 选择参照物 | 场景选择：判断列车、乘客、路边树木的运动状态 | 运动与静止是相对的；参照物不同，结论不同 | 选择 | 无 |

- 闯关：P1 → P2 → P3 → P4，通关解锁「机械运动观测区」徽章。错题给原理解释，可重试，不扣分。
- 首切片只用点选、数值、选择三种题型，不依赖框架第二批（拖拽搭建、排序），可以先行。
- 题型需要共通确认：数值（带单位）与选择题是否由同一题目模型表达（#23 问题）。
- 样例题（原创，供题库录入参考，需教研抽查）：
  1. 用分度值为 1 mm 的刻度尺测量一支铅笔的长度，记录时应包含几位有效数字？（考察估读）
  2. 一辆小车 10 s 内通过 5 m 路程，它的平均速度是多少？
  3. 某车在相同的 10 s 内依次通过的路程分别为 150 m、150 m、150 m，它做的是匀速还是变速运动？
  4. 坐在行驶列车里的乘客，以谁为参照物是静止的？
  5. 「平均速度」与「瞬时速度」的区别是什么？

### 7.1 首关草图（P1，刻度尺与停表读数）
