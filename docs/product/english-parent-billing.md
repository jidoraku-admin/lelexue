# 英语子系统家长端收费方案

- 版本：v0.1
- 状态：产品与实现方案，待技术总监审核；法律文本由法务出具正式版
- 负责人：英语子系统产品设计师
- 关联文档：`english-features.md` §12（账号结构）、`english-user-attraction.md` §10.0 与 §10.1（付费决定）、`english-reward-design.md`

---

## 0. 目的

为技术实现提供家长端收费的完整规则。本文只定义收费的产品行为，法律文本（用户协议、自动续费说明、退款条款）由法务出具正式版。

---

## 1. 收费主体与边界

- **付费主体**：家长账号。学生账号没有任何付费入口，不能独立购买、不能独立续费。
- **免费范围**：学生端的全部学习内容免费，包括每日学习计划、新学据点、练习、单元验收、Boss 战、复习、动画故事。付费不决定孩子能否学会。
- **收费范围**：只收取家长端的增值内容，见 §3。

---

## 2. 套餐与价格

| 套餐 | 内容 | 价格 |
|---|---|---|
| 免费版 | 学生端全部学习内容；家长端基础周报告 | 0 元 |
| 学期包 | 免费版全部内容，加上家长端的深度周报告、考前专项页、学期结束报告 | 首轮 99 元/学期，同时测试 79 元与 129 元两档 |

- **有效期**：学期包自购买之日起 180 天有效。
- **价格分组**：新注册家长按账号随机分入三档价格中的一档，分组结果在购买页显示，同一家长账号的分组固定不变。
- **价格调整**：价格变动只影响新购买，已购买的学期包不变。

---

## 3. 付费功能清单

| 功能 | 免费版 | 学期包 |
|---|---|---|
| 基础周报告（三句话总结与掌握进度图） | 有 | 有 |
| 深度周报告（逐知识点的掌握变化与建议） | 无 | 有 |
| 单元结果页（验收结果与弱点） | 有 | 有 |
| 考前专项页（按学校考试范围生成复习建议） | 无 | 有 |
| 学期结束报告 | 无 | 有 |
| 历史报告查看 | 只读 | 只读 |

**关键约束**：单元结果页中的弱点提示与补救入口对所有家长开放，不因未付费而隐藏。付费功能只增加报告的深度与考前辅助，不阻断学习。

---

## 4. 试用与购买流程

### 4.1 试用

- 家长账号开通时自动开始 14 天试用，试用期间可使用全部付费功能。
- 试用不要求绑定支付方式。
- 试用到期前 3 天，在家长端站内提示；如家长已同意业务通知，可同时发送短信提醒。两种提醒都不在 22:00–08:00 发送。

### 4.2 购买

- 支付方式：微信支付（小程序内支付，需完成商户开通）。
- 购买前提：家长账号已完成实名与监护身份核验。
- 购买页显示：套餐内容、价格、有效期、退款规则与自动续费状态。
- 购买成功后，学期包立即生效，家长端显示到期日期。

### 4.3 自动续费

- **默认关闭**。
- 开启自动续费时，购买页必须清楚显示续费价格、续费周期与关闭方式，并由家长主动勾选确认。
- 续费前 7 天，在家长端站内提示，并说明续费金额。
- 家长可以随时在家长端关闭自动续费，关闭后当前学期包仍然有效，到期不再续费。

### 4.4 退款

- 购买后 7 天内，如果未使用付费功能，可申请全额退款。
- 超过 7 天，或已使用付费功能，不予退款，但学期包有效期内可以继续使用。
- 退款申请在家长端提交，退款到原支付路径。
- 法务需确认退款规则的具体表述。

### 4.5 到期

- 学期包到期后，家长账号自动降级为免费版。
- 付费功能的历史报告保留，只读。
- 到期不影响学生的学习进度、已获得的奖励与学习内容。

---

## 5. 家长端不得出现的内容

- 对学生的付费诱导，包括在学生端出现购买入口、价格或限时提示。
- 限时礼包、虚假稀缺、倒计时式的购买压力。
- 以孩子的学习表现或考试成绩为由催促购买（如"考前不买，孩子会落后"）。
- 把付费与奖励、分享、邀请挂钩（见 `english-viral-growth.md` §8）。
- 深夜（22:00–08:00）发送付费相关提醒。

## 6. 技术实现要求

### 6.1 权益模型

- 权益挂在**家长账号**上，学生账号通过所属家长账号继承权益，不单独持有权益。
- 一个家长账号绑定的多名学生共享同一套权益。
- 权益状态：未开通、试用中、已付费、已到期、已退款。

### 6.2 订单状态

- 订单状态：待支付、已支付、已生效、已退款、已关闭。
- 支付回调必须幂等，同一笔订单重复回调不产生重复权益。
- 每笔订单与对账记录一一对应，对账差异进入人工处理队列。

### 6.3 数据与隐私

- 支付信息只与家长账号关联，支付记录中不包含孩子的姓名或学校。
- 支付与订单数据不用于个性化推荐或对学生的推送。

### 6.4 埋点

| 事件 | 说明 |
|---|---|
| `trial_start` | 试用开始 |
| `paywall_view` | 查看付费页（附触发位置：结果页或专项页） |
| `purchase_success` | 购买成功（附套餐与价格分组） |
| `auto_renew_on` / `auto_renew_off` | 自动续费开启或关闭 |
| `refund_request` / `refund_success` | 退款申请与完成 |
| `plan_expired` | 学期包到期 |

### 6.5 验收标准

- 学生账号在任何页面都看不到购买入口与价格。
- 家长未付费时，单元结果页的弱点与补救入口正常显示。
- 自动续费默认关闭，开启需家长主动勾选。
- 退款规则在购买页与家长端的退款入口一致。
- 到期后，学生的学习内容与进度完全不受影响。
