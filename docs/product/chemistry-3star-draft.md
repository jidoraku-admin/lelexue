# 化学 3★ 判定方式（草稿，#6）

【设计｜化学｜#6】状态：草稿，自审通过，待项目总监审核。不改变已合并的 `docs/product/chemistry.md`；定稿后再并入主设计文档。

## 一、背景

- 化学设计 v0.18 第 2 节写明 3★ 迁移：“新语境正确率 ≥80% 且间隔复习通过一次”。
- “间隔复习”的判定方式未定义，因此代码中调用 3★ 会抛出 `UnsupportedError`（`ChemistryScoring`）。
- 共通规则（`docs/architecture/shared/gamification.md` §9）只定义规则格式，门槛由学科自定；英语的 1★、3★ 尚未发布，英语与物理也只把 2★ 的数值作为起始参考。

## 二、定义

1. **新语境**：同一知识点下，与 1★、2★ 不同的实验情境。化学的新语境题目需满足至少一项：
   - 换用了不同的仪器或装置（例如从集气瓶换成塑料瓶）；
   - 换用了不同的试剂或反应物（例如从过氧化氢换成氯酸钾）；
   - 把现象判断放进未出现过的实验步骤中（例如根据给定现象判断检验结论）。
   题目归属由题库的 `context` 字段标注（学科内字段，不进入共通）。

2. **3★ 判定条件**（同时满足）：
   - (a) 新语境题的正确率 ≥80%，且作答题数 ≥5（统计范围：该知识点在 3★ 中的全部新语境作答）；
   - (b) 间隔复习通过一次。

3. **间隔复习**：
   - 知识点首次达到 2★ 后，系统在**后台配置的间隔时长之后**安排一道该知识点的复习题（与 2★ 中的题目不同）；间隔时长由后台设置，不写死在客户端（项目总监决定，2026-11-24）；
   - 复习题只有一道，答对即为“通过一次”；答错则在下一次作答后重新安排复习，不扣经验；
   - 间隔以作答记录的时间戳计算，使用服务端时间，不依赖本机时间。

4. **经验**：3★ 的经验与 1★、2★ 一样，同一 `(knowledgePointId, level)` 只计一次（沿用 v0.18 的规则）。

## 三、自审（四个维度）

- **技术**：判定只依赖作答记录与时间戳，不引入新的共通接口。时间戳由服务端写入；化学适配层不保存用户的本机时间。待办：若复习调度改由数据平台承担，需要在 #23 提需求。
- **趣味**：复习题以“回访实验”的形式出现（例如“上周的氧气检验，再来一次”），与关卡相同的界面，不增加新的玩法。
- **故事**：复习在“实验室档案”中显示为“复查”，由氧博士提示，不使用惩罚性语言。
- **吸引性**：3★ 对应“能在新实验中用上”，家长在进度页可见这一层；不承诺提分效果（0006）。
