## 1. 定位与目标

**产品定位**：面向 3 年级起的学生，用于语文日常识字、词语、句子与阅读的学习与复习，内容与人教版（2022 修订）三年级上册保持一致（见第 3 节）。

**每天的学习闭环（按真人要求的学习步骤，v0.4）**

学习步骤为：字义与词义 → 句中运用 → 举一反三 → 分析内容主要意思。

1. **字义与词义**：认识字的意思，理解词的意思（识字、词语、偏旁结构）。
2. **句中运用**：在句子中正确使用字和词，理解句子成分、标点与词序。
3. **举一反三**：同类字词换语境、换搭配，独立迁移到新的句子或新的字词上。
4. **分析内容主要意思**：读短文，概括段落大意与全文主要意思。

预习、练习、复习、验收不是新的步骤，而是贯穿上述四步的安排：
- **预习**：在第 1 步之前，读一段本课的原创短文或动画故事，接触本课的生字与词语语境（标注：第 1 步前）。
- **练习**：每一步内都有分层练习，即时反馈并讲解错因。
- **复习**：按间隔复习安排，覆盖四步中已学过的内容。
- **验收**：单元结束时，按四步逐项验收，结果决定是否进入下一单元。

**设计目标**

- **过程指标**：覆盖率、复习保持率、单元测分数率。本稿不写任何成绩结果承诺，遵循 `docs/decisions/0002` 与 `0006`。
- 替代线下重复抄写、机械默写的预习与复习流程，让学生每天有可执行的任务。
- 每个环节都能对应到教材的某项活动或某个生字词，内容不超出教材范围，超出部分按 0006 第二节处理。

## 2. 学习内容与玩法

| 所属步骤 | 学什么 | 玩法（框架玩法 / 学科内） |
| --- | --- | --- |
| 字义与词义 | 识字：认读、字形、部首；词语：词义、近反义词 | 配对：字与拼音（框架）；偏旁选字（学科内）；词语接龙（出牌，框架） |
| 字义与词义 | 偏旁结构：字形拼装 | 拖拽搭建（第二批候选，首版不做） |
| 句中运用 | 句子成分、标点、词序；词语搭配 | 句子词序排序（第二批候选，首版不做）；句中选词填空（学科内） |
| 举一反三 | 同类字词换语境迁移；新句子中的字词运用 | 限时选择（下落选择，框架）；变体题（学科内，由人工编写的题库提供，不依赖 AI 网关） |
| 分析内容主要意思 | 短文理解、段落大意、主要意思 | 阅读选择题（学科内，静态题，不属于框架猜测玩法） |
| 口语 | 朗读、口语交际 | **首版暂缓**。依赖语音能力，不在共通玩法框架内（0010） |

**错误处理**：错误不扣分，给出一条原因解释，允许立即重试。

**节奏**：每次学习约 10 分钟，每个环节有一个明确的小目标。

## 4. 故事与角色（草案）

- **世界观**：一座会说话的"字之森"，树上挂着字的种子，学生帮助森林居民把字种回枝头。
- **主角**：一位 3 年级的小向导（名字与形象待定），陪伴学生完成每一章。
- **故事服务知识点**：每一章的剧情只用本章的生字和词语，超出部分不出现。
- **首切片三章（第 1 单元，字符须在全册字表内）**：第 1 章对应"大青树下的小学"，主角带学生认识"字之森"的第一棵树；第 2 章对应"花的学校"，森林里的花需要按词语重新排列；第 3 章对应"不懂就要问"，遇到不懂的字时向森林居民请教。每章的生字与词语由本课生字表确定。
- **不做虚拟陪伴**：故事角色不做成陪伴、亲密关系形态，避开 `docs/decisions/0006` 第三节提到的合规风险，待法务确认。

## 5. 未成年人与合规

本子系统面向未成年人，遵循以下约定，法务复核完成前不上线：

- 学生账号从属于家长账号，不能独立注册、付费或开启推送（参照英语的共享身份需求，见 #23 的评论）。
- 不收集与学习无关的个人信息；个人信息条款需法务复核。
- 未成年人模式、单日使用与消费限制，依 `docs/decisions/0006` 第三节的法务事项执行。
- **奖励规则（按 0011 执行）**：学习奖励只与掌握挂钩。分享与推荐奖励按 0004 纳入，只奖励真实注册与付费，次数与上限由后台配置；不与班级人数挂钩。
- 学生数据只由私有化部署的模型处理，公有 API 不接收学生个人信息。

## 6A. 玩法需求（#72 共识请求，对应 0010）

首批框架包含配对、下落选择、出牌、猜测；拖拽搭建、排序需两个或以上学科确认后进入第二批。

| 语文玩法（第 2 节） | 对应框架玩法与机制 | 说明 |
| --- | --- | --- |
| 识字找字（字与拼音配对） | 配对（框架玩法） | 框架只提供配对规则，字与拼音的数据由语文适配层提供 |
| 识字找字（由偏旁选字） | 学科内实现 | 偏旁选字不属于框架的猜测玩法（框架的猜测为候选集逐步收窄，参照英语 twenty_questions），留在学科内 |
| 词语接龙 | 出牌（框架玩法） | 词语链的判定规则在语文适配层 |
| 限时识字（可选） | 下落选择（框架玩法） | 首版可不做 |
| 阅读选择题 | 学科内实现 | 静态选择题，不是框架的猜测机制，留在学科内 |
| 偏旁拼装 | 拖拽搭建（第二批候选，未进入框架） | 首切片不做 |
| 句子词序 | 排序（第二批候选，未进入框架） | 首切片不做 |

- **需要共通的部分**：配对、下落选择、出牌的玩法规则与界面骨架。猜测机制语文不使用。拖拽搭建、排序待第二批确认。
- **留在学科内的部分**：生字与词语题目内容、偏旁与字形结构规则、语法提示文案、错因解释、学科的计分与奖励（框架不计分，见 0010）。
- **不在框架内**：朗读评分与语音（首版暂缓）。
