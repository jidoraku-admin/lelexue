- 状态：**v0.1 草案，待项目总监审核**，尚未进入 `stage:design-final`，未经真人定稿不开发

> 版本说明：本稿参照英语子系统 v0.3 的结构与口径编写。产品是**每天的学习工具**，游戏化与故事是提高趣味的手段，不做与学习无关的娱乐内容。

## 1. 定位与目标

**产品定位**：面向 3 年级起的学生，用于语文日常识字、词语、句子与阅读的学习与复习，内容与人教版（教材版本待确认，见第 3 节）保持一致。

**每天的学习闭环**

1. **预习**：读一段本课的原创短文或动画故事，接触本课的生字与词语语境。
2. **识字与新学**：认读、书写、偏旁结构、词语与句子的学习，每个知识点有明确的掌握目标。
3. **练习**：针对刚学内容做分层练习（识记、应用、迁移），即时反馈并讲解错因。
4. **复习**：按间隔复习安排，把旧字词在合适的时间重新出现。
5. **验收**：单元结束时做单元验收，结果决定是否进入下一单元。

**设计目标**

- **内部目标（不得用于任何对外文案）**：学生只用本产品学习，语文成绩达到同年级的较好水平。对外只描述过程指标（覆盖率、复习保持率、单元测分数率），遵循 `docs/decisions/0002` 与 `0006`。
- 替代线下重复抄写、机械默写的预习与复习流程，让学生每天有可执行的任务。
- 每个环节都能对应到教材的某项活动或某个生字词，内容不超出教材范围，超出部分按 0006 第二节处理。

## 2. 学习内容与玩法

| 环节 | 学什么 | 形式 |
| --- | --- | --- |
| 识字 | 认读、字形、部首 | 找字、拼字、收集字卡，解锁故事章节 |
| 偏旁拼装 | 字形结构 | 拖动偏旁组成新字，错误时给出结构提示 |
| 词语 | 词义、近反义词、搭配 | 词语接龙，限时完成，连续正确加分 |
| 句子 | 句子成分、标点、词序 | 调整词序让句子通顺，错误给出语法提示 |
| 阅读 | 短文理解、段落大意 | 读完短文回答选择题，收集线索推进剧情 |
| 口语 | 朗读、口语交际 | 跟读与朗读评分；依赖语音能力，首版可先不做，待共通对话确认 |

**错误处理**：错误不扣分，给出一条原因解释，允许立即重试。

**节奏**：每次学习约 10 分钟，每个环节有一个明确的小目标。

## 3. 教材与内容范围（待真人确认，大事）

1. **教材版本未定**。三方记录不一致，本稿不写具体单元与篇目：
   - 项目说明写"人教版语文"。
   - PR #43（`docs/decisions/0007`，教科版）已关闭未合并，决定是否仍有效需真人确认。
   - 多数学校 3 年级语文使用统编（部编）版，与人教版的单元、篇目、识字顺序不同。
2. **官方目录未核对**。本环境无法访问国家中小学智慧教育平台，三年级上册语文的单元、篇目与生字表需由能访问的一方核对后补入第 6 节。
3. **课文原文不入库**（参照 `docs/decisions/0003`）。本稿只用原创短文、改写和自编闯关内容，只引用课文的篇名与知识点。若要使用课文原文，需先确认版权与授权。
4. **古诗文**：首版不做强制考核，仅作为可选内容，待真人确认范围。

## 4. 故事与角色（草案）

- **世界观**：一座会说话的"字之森"，树上挂着字的种子，学生帮助森林居民把字种回枝头。
- **主角**：一位 3 年级的小向导（名字与形象待定），陪伴学生完成每一章。
- **故事服务知识点**：每一章的剧情只用本章的生字和词语，超出部分不出现。
- **不做虚拟陪伴**：故事角色不做成陪伴、亲密关系形态，避开 `docs/decisions/0006` 第三节提到的合规风险，待法务确认。

---

## 5. 未成年人与合规

本子系统面向未成年人，遵循以下约定，法务复核完成前不上线：

- 学生账号从属于家长账号，不能独立注册、付费或开启推送（参照英语的共享身份需求，见 #23 的评论）。
- 不收集与学习无关的个人信息；个人信息条款需法务复核。
- 未成年人模式、单日使用与消费限制，依 `docs/decisions/0006` 第三节的法务事项执行。
- **零奖励原则**：奖励只与掌握挂钩，不与邀请、分享、注册、付费或班级人数挂钩。
- 学生数据只由私有化部署的模型处理，公有 API 不接收学生个人信息。

## 7. 四个维度自审（v0.1）

| 维度 | 结论 | 说明 |
| --- | --- | --- |
| 技术 | 需修改 | 依赖 #23 的题库与游戏化接口，尚未回复；语音能力未评估；偏旁拼装的交互需要单独组件 |
| 趣味 | 通过（草案） | 每个环节有明确小目标，反馈及时；"找字、拼字"是否有趣需要原型试玩验证 |
| 故事 | 需修改 | 世界观已有，主角与章节线未定；需逐章核对剧情只用本章生字词 |
| 吸引性 | 需修改 | 首次体验能否在几分钟内获得成就感尚未验证；留存机制需避免诱导式设计 |

四个维度未全部通过，本稿不进入 `stage:design-final`。
