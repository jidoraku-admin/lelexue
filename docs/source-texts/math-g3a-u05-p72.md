# 三年级上册 第 5 单元 线和角（书页 72，练习十四、成长小档案）

- 练习十四（书页 72）：
  - 第 1 题：右面的直线上有 A、B、C 三个点，共有（ ）条射线，（ ）条线段。
  - 第 2 题：下面的图形中各有几个角？几条线段？（图形：三角形、正方形、五边形、八边形；每个图形下方各有“( )个角”“( )条线段”两处空格。）提示语：用圆规比一比每个图形中各条线段的长度，你发现了什么？
  - 第 3 题：（1）直线 AB、CD 相交于点（ ）。（2）两条直线相交组成了几个角？说一说。（图示：两条相交直线。）
  - 第 4 题：拿一个正方体盒子，先看看每个面上有几个直角，再数一数盒子上一共有多少个直角。换一个长方体盒子再数一数，你发现了什么？（图示：正方体。）
- 「成长小档案」（书页 72）：栏目标题「本单元结束了，你想说些什么？」，气泡提示“旁边处处都有角，太有意思啦！”，填写项「我的收获是：」，留有两行空白。
