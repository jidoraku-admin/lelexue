# 三年级上册 第 5 单元 线和角（书页 66–67，角的认识续、直角）

- 「指一指」：哪里有角？（题图：纸风车、路标、交通信号灯等。）
- 要点（原创概括）：上面用红线标出的角都是直角。
- 提示语：每个三角尺上都有一个直角。要知道一个角是不是直角，可以用三角尺上的直角比一比；你能用纸折一个直角吗？
- 第 2 题（书页 67）：可以用三角尺画直角（图示：三角尺的直角边对齐，画出一个直角）。
- 页脚：67
- 「做一做」（书页 68）：
  - 第 1 题：课桌面可以看作什么图形？这个图形中有直角吗？
  - 第 2 题：数一数下面的图形中各有几个直角（图形：长方形、正方形、三角形）。
