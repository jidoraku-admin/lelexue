# 三年级上册 数学 认识质量单位（书页 33）与 称重我很行（书页 34）

- 「认一认」：读出下面物体的质量。三个题图：香蕉（称出几克）、袋装草莓（称出几千克）、人体体重秤（称出几千克）。提示语要点：指针指着几，就表示所称的物体有几克或几千克。
- 「小调查」：调查下面的动物有多重，并填表（表头：动物；列出几种动物，如蜻蜓、麻雀、大熊猫、北极熊、河马、蓝鲸等，并填写体重）。
- 页脚：33
- 书页 34「称重我很行」：「比一比」：找一些物品掂一掂，比一比轻重。图示：桃子、橙子、苹果等，提示语要点：一个比另一个重，这样比不出来，需要称一称再比较。
