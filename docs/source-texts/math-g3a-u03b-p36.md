# 三年级上册 质量（无编号，位于第 3 单元与第 4 单元之间，待核对）（书页 36，称重大挑战）

- 称重大挑战（页首）：找一些常见的物品，先估一估质量，再称一称。（气泡提示：一个笔袋约重 200 克，一本字典约重 400 克。）
- 如果没有秤，只给你一些 200 克一袋的盐，你能想办法“称”出下面物品的质量吗？（表格：物品——1 个手电筒、1 个水杯、1 盆花；质量——第一格约 2 袋盐，其余留空。）
- 图示：用花盆作标准的称重过程（气泡：先把花盆放到一个空盘中，再放入注满的水；另有同学用手拿“称”的物品进行比较）。
- 想一想：你还想用哪些已知质量的物品作标准呢？试一试！这样称重，你有什么体会？
