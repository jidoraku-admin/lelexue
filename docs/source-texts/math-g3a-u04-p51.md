# 三年级上册 第 4 单元 多位数乘一位数（书页 51，乘法估算）

- 第 7 题：学校组织 987 名学生去植物园参观。8000 元买门票够不够？（图示：两名学生与植物园大门。）
- 阅读理解（原创概括）：已知学生人数和门票价格，要解决“8000 元买门票够不够？”的问题。
- 分析解答：
  - 精确算法（页内竖式）：987 × 8 = 7896，7896 < 8000。
  - 估算法（页内气泡）：只是问钱数够不够，可以估一估。把 987 看成 1000，987 < 1000，8 × 987 < 8 × 1000 = 8000。
  - 答：8000 元买门票够了。
- 回顾反思（原创概括）：有时用估算就能很快地解决问题；把人数估大、钱数都够，买东西一定够。
- 做一做：陈老师要买 5 双轮滑鞋，每双 218 元，1000 元够吗？（图示：轮滑鞋，标注 218 元/双。）
