# 三年级上册 第 6 单元 分数的初步认识（书页 90，整理和复习）

- 「整理和复习」开篇：回顾本单元学习过程，你有什么收获？把你对分数的认识整理一下吧。
- 知识结构图（原创概括）：
  - 以圆形与线段为例，1/4 表示把一个整体平均分成 4 份中的 1 份；3 个 1/4 是 3/4；4 个 1/4 是 4/4，就是 1。
  - 比较大小：1/4 < 3/4 < 1。
  - 简单计算：1/4 + 3/4 = 4/4 = 1；1 − 1/4 = 3/4；1 − 3/4 = 1/4。
- 反思题：这一单元我们认识了分数，它与以前学习的整数有什么联系和区别？在学习中用到了什么新的方法？你还想研究什么问题？
- 配图对话（两条气泡，文字较小，以截图为准）：分数与整数之间的联系与区别；分数表示整体与部分之间的关系。
