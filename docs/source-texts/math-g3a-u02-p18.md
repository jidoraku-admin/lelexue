# 三年级上册 第 2 单元 混合运算（书页 18，整理和复习）

- 栏目：整理和复习。引导学生回顾本单元收获，并用“知识结构图”整理内容，请学生仿照示例自行整理。
- 知识结构图（原创概括）：以“混合运算”为中心，分三支：
  - 运算顺序：没有括号时，只有加减法或只有乘除法，从左往右依次计算；加减乘除混合时，先算乘除、后算加减。有括号时，先算括号里的。
  - 解决多步计算的实际问题：分成几个小问题，逐步解决；列综合算式表示解答过程。
- 配图示例：三个算式例子，分别展示 35 − 23 + 18、73 − 36 + 24 等无括号运算，以及 25 + (32 − 27) × 8 等有括号运算（以截图为准，待复核）。
- 思考题（原创概括）：解决需要多步计算的实际问题时，你是怎样思考的？你掌握了哪些新的方法？请与同学交流。
- 学生对话气泡（原创概括，不引用原文）：分解成小问题、一步解决一个小问题；用线段图分析数量关系；列综合算式并用括号改变运算顺序；学习多步混合运算的计算方法。
