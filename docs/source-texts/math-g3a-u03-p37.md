# 三年级上册 数学 小讲堂（书页 38–39）

- 「你还有哪些感兴趣的问题？」：生活中还有哪些质量单位和秤？古代的质量单位和秤与现在一样吗？俗语中有质量单位，这些质量单位是什么意思呢？
- 「选择一个你感兴趣的问题，研究一下，给大家讲一讲。」
- 「小讲堂开播啦」：分享古代的质量单位（要点：古代的质量单位与现在不同，常见有“公斤”“斤”“两”等，并与现行单位做换算）。
- 换算图示（原创整理）：1 公斤 = 2 斤；1 斤 = 10 两；1 公斤 = 1 千克；1 斤 = 500 克。
- 生活中的常见秤（杆秤、天平等）以图示说明。
