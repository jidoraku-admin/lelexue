# 三年级上册 第 5 单元 线和角（书页 71，整理和复习）

- 「整理和复习」开篇：本单元学习了线和角，一起来整理一下「知识结构图」。
- 知识结构图（原创概括）：
  - 线段：有两个端点，可以度量；两点之间线段最短。
  - 射线：有一个端点，可以向一端无限延伸，不可度量。
  - 直线：没有端点，可以向两端无限延伸，不可度量。
  - 角：由一个顶点、两条边构成；分为直角、锐角、钝角。（分类图中标注：比直角小的是锐角，比直角大的是钝角。）
- 反思题（书页 71）：在这个单元的学习中，你有哪些收获？你还想研究哪些问题？和同学说一说吧。
- 配图对话（人物提示语，原创概括）：认识了线段、射线、直线的联系与区别；以前我会用测量的方法比较线段的长短，现在我还学会了用圆规……；我发现以前学过的图形上都有线段和各种角；我还想进一步研究角的大小。
