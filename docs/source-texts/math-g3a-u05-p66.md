# 三年级上册 第 5 单元 线和角（书页 65–66，角的认识）

- 「2. 角的认识」（书页 65）：生活中常见各种角的物品（剪刀、钟面、三角板等）。
- 要点（原创概括）：从一个点引出两条射线，得到的图形是角。这个点是角的顶点，两条射线是角的边。角用符号“∠”表示，如图中的角可以记作“∠1”。
- 活动：打开折扇，看看角有什么变化？提示语：张口越大，角越大。
- 「画一画」（第 1 题）：先画一个点，再以这个点为顶点，借助尺子向不同的方向画两条射线，就画出一个角。
