# 三年级上册 第 5 单元 线和角（书页 63–64）

- 书页 63 续（要点，原创概括）：用圆规比较线段长短时，把圆规的一个针尖固定在一条线段的一端，另一脚对准另一端，再把圆规转手柄比较；可以用“<”“>”表示比较结果。
- 「想一想」：像上面那样比较线段 AB 和线段 CD 的长短，点 A 与点 C 重合。（1）如果点 B 与点 D 重合，那么 AB ___ CD；（2）如果点 B 在点 D 的右侧，那么 AB ___ CD。
- 页脚：63
- 练习十二（书页 64）：
  - 第 1 题：用圆规比一比右面每组中两条线段的长短（两组线段，填写 AB ___ CD）。
  - 第 2 题：在直线 l 上画出长为 3 厘米的线段 AB，再用圆规在直线 l 上作线段 BC，使 BC = AB。
  - 第 3 题：下面的图形，（ ）是线段，（ ）是直线，（ ）是射线。（图形编号 ①–⑦。）
  - 第 4 题：按要求画一画（页面续）。
