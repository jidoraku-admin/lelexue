- 「做一做」第 2 题：观察下面各图的涂色部分，想一想，填一填（图形：正五边形分块、正方形分块、长方形分块）。
  - 图 1：3 个 1/（ ）是（ ）。
  - 图 2：（ ）/（ ）里面有（ ）个 1/9。
  - 图 3：3 个（ ）/（ ）是（ ）。
- 杯子对比（情境）：2/5 杯果汁比 1/5 杯多；2/5 比 1/5 大；2/5 > 1/5。（图示：两杯果汁，分别标注 1/5 杯、2/5 杯。）
- 「做一做」第 3 题：
  - （1）涂一涂，比一比（图示：3/10 与 7/10 的方格图，6/6 与 5/6 的圆图）。你发现了什么？提示语：平均分成相同的份数后，涂的份数越多，对应的分数越大。
  - （2）比一比（图示：1/2 与 1/3 的图，分成相同大小的两组并比较）。提示语：等分的份数越多，每份就越小；把它们等分成相同的份数进行比较。
