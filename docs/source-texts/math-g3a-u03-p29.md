# 三年级上册 第 3 单元 毫米、分米和千米（书页 29）

- 整理和复习：
  - 表格（量：长度；计量单位及单位间的进率）：请你填一填，填入“( )米 = ( )分米”“( )厘米 = ( )毫米”等进率（空格以截图为准）。
  - 讨论提示（气泡）：这一单元学习的毫米、分米和千米，与前面学习的厘米、米一样，都是人们规定的长度单位标准；可以自己选择一些长度作为度量标准，进行估测；还可以思考是否有比千米更大、比毫米更小的长度单位。
