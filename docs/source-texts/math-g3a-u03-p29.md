# 三年级上册 第 3 单元 毫米、分米和千米（书页 29，整理和复习、练习七）

- 整理和复习（原创概括）：回顾已学的长度单位（毫米、厘米、分米、米、千米）；讨论人们规定的长度单位标准，以及用身边的物体作度量标准进行估计；思考是否还有比千米更大、比毫米更小的长度单位。
- 练习七：
  - 第 1 题：在（ ）里填上合适的长度单位。（1）马拉松长跑比赛全程约 42（ ）；（2）语文书厚约 6（ ）；（3）过街天桥长约 30（ ）。
  - 第 2 题：在○里填上“>”“<”或“=”：90 毫米○9 厘米；4 米○30 分米；2 千米○3000 米；400 厘米○3 米；5 厘米○5 分米；6 分米○500 毫米。
