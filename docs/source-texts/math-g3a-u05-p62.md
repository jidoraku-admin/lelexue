# 三年级上册 第 5 单元 线和角（书页 62–63）

- 「做一做」第 1 题：辨认图中的线段、射线和直线（①–⑥ 六个图形，填写哪些是线段、哪些是射线、哪些是直线）。
- 第 2 题：李叔叔要从家去超市，走哪条路最近？（图示：多条路线，编号 ①②③。）
- 要点（原创概括）：两点之间所有连线中，线段最短，这条线段的长度叫作两点间的距离。
- 页脚：62
- 书页 63「用圆规比较线段的长短」：
  - 第 1 题：比较右面两条线段的长短。（线段 AB、CD。）
  - 提问：怎样比较？可以用尺分别量出它们的长度再比较；不用尺测量长度，还有其他办法进行比较吗？
  - 圆规：用来画圆的工具，也可以用它量出同样长度的线段（图示：圆规的两脚、手柄）。
