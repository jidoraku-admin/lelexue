# 教材原文（仅内部核验，不参与打包发行）

依据：`docs/decisions/0012-textbook-source-texts-internal.md`。

- 本目录只存教材原文的文字（课文、题干、对话），不存插图、音频、视频。
- 文件名：`<科目>-g<年级><学期>-u<单元两位>-p<页码>.md`，例如 `math-g3a-u01-p01.md`。
- 每个文件头必须写：来源网址、采集日期、采集人（对话名与签名）、页码，以及「仅内部核验，不得用于产品或发行」。
- 禁止任何代码、资源、配置引用本目录；禁止把原文拷入 `apps/`、`packages/`、`services/`、`docs/data/`。
- 核验时只引用页码与要点，不把原文段落写入产品文件。
