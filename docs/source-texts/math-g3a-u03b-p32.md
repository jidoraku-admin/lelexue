# 三年级上册 质量（无编号，位于第 3 单元与第 4 单元之间，待核对）（书页 32，认识质量单位）

- 说一说：小组交流一下课前调查的情况。（对话气泡：我在盆秤、天平和电子秤上找到了“克”；我在下面几种秤上找到了“千克”；我的体重是 25 千克。）
- 认识质量单位（原创概括）：克（g）、千克（kg）是生活中常用的表示物体质量的单位。计量比较轻的物品，常用“克”作单位；计量比较重的物品，常用“千克”作单位。
- 图示：天平、秤、电子秤与人体体重（如“我的体重是 25 千克”）等称重场景。
- 进率：1 千克 = 1000 克。
- 注释（原创概括）：“千克”在日常生活中也叫“公斤”。
