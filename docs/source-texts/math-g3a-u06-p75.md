# 三年级上册 第 6 单元 分数的初步认识（书页 75，几分之一续、做一做）

- 「试一试」：用你自己的方法表示 1/3、1/5……（图示：线段与图形分别平均分成 3 份、5 份，标注 1/3、1/5）。
- 归纳（原创概括）：像 1/2、1/3、1/4、1/5 这样的数，都是分数。
- 分数各部分名称（框图）：分子（1）表示取了几份；分数线；分母（2）表示平均分成了几份。读作：二分之一。
- 「做一做」：
  - 第 1 题：下面各图中的涂色部分是整个图形的几分之几？请你用分数表示出来（图形：半圆、长方形、八边形、十字形等）。
  - 第 2 题：想一想，填一填（图示：六边形分块纸片，填“（ ）盒”“（ ）杯”的分数；一杯果汁，喝了一杯的几分之几，还剩几分之几）。
  - 第 3 题：□ 是一个图形的 1/4。这个图形可能是什么形状？请你在方格纸上画出来。（图示：方格纸，其中一格已涂色。）
