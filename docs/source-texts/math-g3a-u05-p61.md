# 三年级上册 第 5 单元 线和角（书页 61–62）

- 单元标题：线和角；第一节「1. 线段、射线、直线」。
- 情境图：拉紧的线、弓弦等，都可以看作线段（线段有两个端点，用大写字母表示）。
- 线段的表示方法：用两个端点的字母表示（如线段 AB）。
- 射线：把线段向一端无限延伸，得到一条射线，只有一个端点，可以用端点和射线上另一点表示（如射线 AB）。
- 直线：把线段向两端无限延伸，得到一条直线，没有端点；可以用直线上两个点表示（如直线 AB），也可以用一个小写字母表示（如直线 l）。
- 页脚：61
- 书页 62「想一想」：线段、射线与直线有什么联系和区别？（对话框要点：线段有两个端点、不能量出长度的是直线；线段可以量出长度；直线和射线都可以无限延伸。）
