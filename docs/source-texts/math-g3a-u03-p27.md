# 三年级上册 第 3 单元 毫米、分米和千米（书页 27，练习六）

- 第 1 题：用下面的出行方式行 1 千米需要多长时间？圈出合适的答案。（图示：步行，选项 15 秒、15 分、1 小时；骑车，选项 4 秒、4 分、1 小时；汽车，选项 1 秒、1 分、1 小时。）
- 第 2 题：7 分米 = ( )厘米；6000 米 = ( )千米；300 毫米 = ( )分米；50 分米 = ( )米；8 千米 = ( )米；3 米 = ( )毫米。
- 第 3 题：跑道一圈长 400 米，小明跑了 5 圈，他一共跑了几千米？
- 第 4 题：一个游泳池长 50 米，如果游 1 千米，要游多少个来回？（页内气泡：往返一次就是一个来回。）
- 第 5 题：估计一下学校教学楼大约有多高。说一说你是怎样估的。
- 第 6 题：20 毫米 + 30 毫米 = ( )厘米；1 千米 − 700 米 = ( )米；3 米 − 1 米 = ( )分米；2 米 + 3 厘米 = ( )厘米。
- 第 7 题：王老师家距学校 3 千米，他每天从家步行到学校，每分钟大约走 100 米。王老师 7:00 从家出发，7:45 能到校吗？
