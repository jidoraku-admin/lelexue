# 三年级上册 第 3 单元 毫米、分米和千米（书页 26–27，问题解决：估测距离）

- 第 3 题情境：从你家到学校大约有多远？怎么估计呢？（阅读理解：要估计一段距离，需要先找到一个标准……）
- 对话框要点（原创概括）：一步大约 50 厘米，两步大约 1 米，走 1000 米约 500 步；一分钟大约走 70 米，走到学校约需 10 分钟；公交车上一共要坐 3 站，每站大约 500 米，合计 1500 米。
- 「回顾反思」：估计距离需要先选择一个长度作为标准；可以通过手机导航验证估计的结果（图示为实验小学到某处 11 分钟、757 米）。
