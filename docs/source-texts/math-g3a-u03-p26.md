# 三年级上册 第 3 单元 毫米、分米和千米（书页 26，问题解决：估测）

- 第 3 题：从你家到学校大约有多远？怎么估计呢？
  - 阅读理解（原创概括）：估计一段距离，需要先找到一个标准。
  - 分析解答（原创概括，以截图为准）：有人以一步约 50 厘米、两步约 1 米估算，走 1000 步左右，约 500 米；有人以一分钟约 70 米、10 分钟约 700 米估算；有人以公交车每站约 500 米、坐 3 站约 1500 米估算。
  - 回顾反思：估计距离需要先选择一个长度作为标准；可以通过手机导航验证估计的结果（页内地图为“步行到实验小学 11 分钟 757 米”，具体数字以截图为准）。
- 做一做：估计校园的长、宽各是多少。
