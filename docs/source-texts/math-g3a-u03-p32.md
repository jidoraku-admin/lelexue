# 三年级上册 数学 认识质量单位（书页 32–33）

- 书页 32 页脚前：克（g）、千克（kg）是生活中常用的表示物体质量的单位。计量比较轻的物品，常用「克」作单位；计量比较重的物品，常用「千克」作单位。
- 图示：1 千克 = 1000 克。
- 注释：“千克”在日常生活中也叫“公斤”。
- 页脚：32
- 书页 33 起：「说一说」（小组交流课前调查的情况）。图示：盘秤、天平、电子秤；提示语：在盘秤、天平和电子秤上找到了“克”；在下面几种秤上找到了“千克”；我的体重是 25 千克。
- 书页 33 起：大象体重的提问，卡车上秤的提问（题图为大象与卡车，配“汽车衡”）。
- 页脚：33
