# 三年级上册 第 2 单元 混合运算（书页 13，解决问题：两级计算）

- 第 5 题（页首）：在劳动课上，小明做了 8 朵花，小红做的比小明少 3 朵，小军做的是小红的 2 倍。小军做了多少朵花？
- 阅读理解（线段图，原创概括）：小明做的朵数为 8 朵；小红比小明少的 3 朵；小军做的朵数为“?朵”。
- 分析解答（页内两种思路，原创概括）：先求小红做了几朵：8 − 3 = 5（朵）；再求小军做了几朵：5 × 2 = 10（朵）。综合算式：(8 − 3) × 2 = 10（朵）。
- 回顾（页内对话，原创概括）：知道了小明做的朵数，可以先求小红做的朵数，再求小军做的朵数。
