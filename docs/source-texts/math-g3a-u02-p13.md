# 三年级上册 第 2 单元 混合运算（书页 13，解决问题：两级计算）

- 例题（题干以截图为准，待复核）：小明做了 8 朵花，小红做的朵数比小明少 3 朵，小军做的朵数是小红的 2 倍。小军做了多少朵？
- 阅读理解（线段图）：小明做的朵数 8 朵；“少的 3 朵”；小红做的朵数；小军做的朵数“？朵”。
- 分析解答：两种思考方法都是先求出小红做的朵数，8 − 3 = 5（朵）；再求小军做的朵数，5 × 2 = 10（朵）。综合算式：(8 − 3) × 2 = 10（朵）。
