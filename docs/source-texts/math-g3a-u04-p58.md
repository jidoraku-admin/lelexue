# 三年级上册 数字编码（书页 58–59）

- 「说一说」续（书页 58）：（1）对双胞胎的公民身份号码会一样吗？为什么？（2）观察上面这些编码，它们有什么特点？
- 注释（原创概括）：公民身份号码中的校验码是根据前 17 位数字计算的，可以是 0–10 中的任何一个数；当校验码是 10 时，用罗马数字 X 表示。校验码可以用来判断号码是否正确。
- 页脚：58
- 书页 59「编制学号」：我们已经了解了一些数字编码的含义和编制方法，让我们试着给全班同学编一下学号吧！
- 「小组同学讨论一下，学号中需要包含哪些信息？可以怎样设计？」（对话框要点：班级用两位数字表示，年级每年都要变；还需要包含性别、座号等信息；信息多，怎么分开呢？）
- 「试一试」：设计一个编制学号的方案，写出每部分表示的含义。
- 「说一说」：（1）向大家介绍你们小组设计的编码方案，说明设计的理由。（2）如果给全校学生编学号，你们的方案还可行吗？（页面文字在截图中未完整显示，待下一屏核对。）
