# 三年级上册 第 3 单元 毫米、分米和千米（书页 25，千米的认识）

- 千米的认识（原创概括）：运动场的跑道一圈约 400 米，2 圈半约 1000 米。1000 米用较大的单位表示是 1 千米，记作 1 千米 = 1000 米。
- 想一想（第 2 题）：3 千米 = ( )米；5000 米 = ( )千米。（页内有提示：1 千米是 1000 米，3 千米是几个 1000 米；1000 米是 1 千米，5000 米里面有几个 1000 米。）
- 做一做：
  - 第 1 题：到操场上量出 100 米的距离，走一走，看看有多远。几个这样的长度是 1 千米？
  - 第 2 题：放学后和家长一起走 1 千米的路程，体验 1 千米有多远。
  - 第 3 题：（图示：数轴，0 与 2000 米、1 千米等刻度，填空为“( )米”“( )千米”。）
- 注释（原创概括）：日常生活中，“千米”也叫“公里”。
