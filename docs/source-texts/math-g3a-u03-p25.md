# 三年级上册 第 3 单元 毫米、分米和千米（书页 25）

- 标题：千米的认识
- 段落 1：测量比较长的路程，通常用千米（km）作单位。
- 段落 2：运动场的跑道一圈约 400 米，2 圈半约 1000 米。1000 米用较大的单位表示是 1 千米。
- 图示：1 千米 = 1000 米。
- 「做一做」第 2 题：3 千米 = （ ）米；5000 米 = （ ）千米。（提示：1000 米是 1 千米。）
- 「做一做」第 1 题：走一走，走出 100 米的距离，看看有多远；几个这样的长度是 1 千米。
- 「做一做」第 3 题：数轴：0 到 1 千米，以及 2000 米处，填写（ ）米、（ ）千米。
- 页脚：25
- 注释：“千米”在日常生活中也叫“公里”。
