# 三年级上册 质量（无编号，位于第 3 单元与第 4 单元之间，待核对）（书页 31，曹冲称象的故事）

- 故事与原理（原创概括）：用等量代换的思路，把大象的质量转换为船上石头的总质量；先在船身画线记下水位，再用石头替换大象，让船回到同一水位，最后分次称出这些石头的质量并相加。
- 图示（以截图为准，待复核）：大象的质量 = 船上石头的总质量 = 各次称出石头质量的和。
- 对话气泡（原创概括）：提出“等量的等量相等”“总量等于各分量之和”，并引出“还有什么疑问”“怎么知道石头有多重”等追问。
- 活动准备：课前调查，生活中称重的工具有哪些？用什么单位记录或表示物体有多重？
