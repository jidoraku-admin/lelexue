# 三年级上册 数学 阅读材料：曹冲称象的故事（书页 30–31）

- 页脚 30 之后起，题图为大象与船。
- 引导问题：你知道曹冲称象的故事吗？请说一说曹冲称象的步骤和方法。
- 步骤图示（三步）：赶大象上船，记下水面位置；把大象赶下船，往船上装石头，直到水面到同一位置；分几次称出船上石头的重量，相加得到大象的质量。
- 原理图示：大象的质量 = 船上石头的总质量 = 各次称出的石头质量之和。
- 提示语要点：质量相等的等量相等；总量等于各分量之和。
- 「你还有什么疑问？」：大象到底有多重？怎么知道石头有多重？
- 「活动准备」：课前调查，生活中称重的工具有哪些？用什么单位记录或表示物体有多重？
