# 三年级上册 第 3 单元 毫米、分米和千米（书页 30）

- 练习七（续）：
  - 第 3 题：下面的说法正确吗？正确的画“√”，错误的画“×”。（1）一本小学生字典厚 40 毫米。（2）一条毛巾长 7 厘米。（3）小红家和奶奶家相距 50 千米，她最好步行去。
  - 第 4 题：从小军家到少年宫怎么走最近？要走多少米？把最近的路线描出来。（图示：超市、社区医院、少年宫、宾馆、街心花园、小军家之间的道路，标注 600 米、900 米、500 米、920 米、600 米等，以截图为准。）
  - 第 5 题：估计学校篮球场的长、宽各是多少。说一说你是怎样估的。
  - 第 6 题：小亮想知道一捆铁丝一共有多少米。请你帮他设计一个研究方案，并写出主要步骤。
- 成长小档案（原创概括）：栏目提示“本单元结束了，你想说些什么？”，配图气泡提示“我知道 1 毫米有多长了”，并留出“我的收获是：”的填写空白。
