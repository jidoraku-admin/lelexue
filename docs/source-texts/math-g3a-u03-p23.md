- 第 2 题：在( )里填上合适的长度单位。（图示：水杯高 1( )；铅笔粗 7( )；牙刷长 16( )。）
- 第 3 题：90 厘米 = ( )分米；100 毫米 = ( )分米；2 米 = ( )厘米；6 分米 = ( )厘米。
