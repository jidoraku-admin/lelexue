# 三年级上册 第 3 单元 毫米、分米和千米（书页 23，练习五）

- 练习五 第 1 题：量出每条边的长度（用毫米作单位）。图示为若干三角形、四边形。
- 练习五 第 2 题：在括号里填合适的长度单位。物品：杯子高 1（ ）、铅笔长 7（ ）、牙刷长 16（ ）。
- 练习五 第 3 题：换算。90 厘米 = （ ）分米；100 毫米 = （ ）分米；2 米 = （ ）厘米；6 分米 = （ ）厘米。
- 练习五 第 4 题：在○里填“>”“<”或“=”。5 分米○5 毫米；8 毫米○2 厘米；6 厘米○60 毫米；1 米○7 分米；9 毫米○3 分米；4 分米○4 米。
- 练习五 第 5 题：按要求画线段。（1）画一条长 5 厘米 8 毫米的线段；（2）画一条比 1 分米短 3 厘米 5 毫米的线段。
