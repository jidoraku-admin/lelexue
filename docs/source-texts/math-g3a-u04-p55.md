# 三年级上册 第 4 单元 多位数乘一位数（书页 55–56，整理和复习、练习十一）

- 「整理和复习」（书页 55）：下面是小明整理的本单元的“知识结构图”，请你也整理一下。
- 结构图要点（原创概括）：多位数乘一位数分为「口算乘法」（如 300 × 4、12 × 3 等，先按整十、整百计算）、「笔算乘法」（列竖式，逐位相乘，有进位时加上进位的数）、「问题解决」（如果知道数量较大，找准数量关系，就能解决问题）。
- 提问：这个单元我们学习的知识，和之前学习的乘法有什么联系和区别？你还想探究哪些问题？和同学交流一下。
