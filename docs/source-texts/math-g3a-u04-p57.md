# 三年级上册 数字编码（书页 57–58）

- 单元标题：数字编码（书页 57）。
- 情境图：生活中有许多地方都有数字编码，这是人们根据实际需要，按照一定标准给事物编制的“身份号码”。图示：银行卡号、书籍条形码（ISBN）、手机号码。
- 「活动准备」：选择一种你在生活中见过的数字编码，调查它表示的信息。
- 「认识数字编码」（书页 58）：
  - 「说一说」：你找到了哪种数字编码，说一说它们是怎样编制出来的。
  - 公民身份号码（原创概括）：共 18 位数字组成，包含地址码、出生日期码、顺序码和校验码。
  - 示例分段：地址码（前 6 位，表示省、市、县）；出生日期码（年、月、日）；顺序码（表示性别：奇数为男，偶数为女）；校验码（最后一位）。
  - 邮政编码（6 位数字组成，表示收件人地址，前两位表示省、直辖市、自治区）。
