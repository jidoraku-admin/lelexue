# 三年级上册 第 7 单元 复习与关联（书页 93，数量关系）

- 「数量关系」（书页 93）：
  - 你会用四则运算解决哪些问题？在解决这些问题的时候，你有什么好的方法？
  - 对话提示（原创概括）：要找一数量中有哪些关系，思考先求什么、再求什么；画线段图可以帮助分析数量之间的关系。
  - 线段图情境（图示）：气泡依次为“小明做的朵数”“小红比小明少做 3 朵”“小红做的是小军的 2 倍”“小军做的朵数”；线段图中小明一段标注“8 朵”，小红一段比小明少“3 朵”，小军一段标注“?朵”。
- 对话提示（原创概括）：列式时，既可以分步列式，也可以列综合算式；计算可以帮助我们解决实际问题，要根据需要选择估算还是精确计算。
