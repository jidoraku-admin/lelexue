# 三年级上册 第 4 单元 多位数乘一位数（书页 49，0 的乘法）

- 第 4 题（例题，页首）：（图示：7 只猴子各拿着一个盘子，盘子里有桃子。）7 个盘子里一共有多少个桃子？
  - 小红用加法算：0 + 0 + 0 + 0 + 0 + 0 + 0 = 0（个）。
  - 小明用乘法算：0 × 7 = 0（个），7 × 0 = 0（个）。
  - 想一想：0 × 3 = □；9 × 0 = □；0 × 0 = □。
- 结论（原创概括）：0 和任何数相乘都得 0。
- 做一做：
  - 第 1 题（口算）：0 × 2；5 × 0；0 × 6；0 × 8；2 × 0；5 + 0；6 × 0；0 + 8。
  - 第 2 题：在○里填上适当的运算符号：4 ○ 0 = 0；0 ○ 4 = 4；0 ○ 4 = 0；7 ○ 7 = 0；10 ○ 0 = 0；0 ○ 0 = 0。
