# 三年级上册 质量（无编号，位于第 3 单元与第 4 单元之间，待核对）（书页 33）

- 页首（对话气泡，原创概括）：我知道一头大象有好几吨重吗？；（汽车衡）卡车从上面开过就知道有多重。
- 说明（原创概括）：计量较重的或大宗物品的质量，通常用吨（t）作单位。进率：1 吨 = 1000 千克。
- 认一认：你能读出下面物体的质量吗？（对话气泡：指针指着几，就表示所称的物体有几克或几千克。）
- 填空（图示：三种称重场景——面包、一袋苹果或小西红柿、人体体重；填空为“( )克”“( )千克”“( )千克”。）
- 小调查：调查下面的动物有多重，并填表。（表头：动物——蜻蜓、麻雀、大熊猫、北极熊、河马、蓝鲸；行：质量，留空。）
