# 三年级上册 数学 称重大挑战（书页 36–37）

- 书页 36「称重大挑战」：找一些常见的物品，先估一估质量，再称一称。
- 表格：物品（1 个手电筒、1 个水杯、1 盒花）；质量列（约 2 条鱼？约 2 条盒等，用于估测对比）。
- 提示语要点（原创概括）：可以把一样物品当作标准，把另一件与之比较；用曹冲称象的方法，先把花盆放到一个空盆里，再放入注有水的水槽，测出花盆的质量。
- 「你还想用哪些已知质量的物品作标准呢？试一试吧！这样称重，你有什么体会？」
