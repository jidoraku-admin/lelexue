# 0012 教材原文内部存放（不参与打包发行）

- 状态：真人决定（2026-11-24），法务复核（0006）待办
- 关联：0003（教材内容来源）、0006（未成年人与个人信息条款，法务复核）、#25、#68

## 一、决定

1. 为核验知识点，允许在 GitHub 仓库的 `docs/source-texts/` 目录内保存教材原文（课文、题干、对话的文字），仅供团队内部核验。
2. 原文不参与任何打包发行：不得被 `apps/`、`packages/`、`services/` 下的任何代码、资源或配置引用；不得出现在学生端、家长端、Web 构建或应用包中。
3. 产品中的题目、故事、对话仍一律原创（0003 不变）。核验结论写入 `docs/data/`，只写页码与「已核对」，不拷贝原文段落。

## 二、与 0003 的关系

- 本决定在「保存原文用于内部核验」这一范围内修改 0003 中「教材原文不入库」的规定。0003 中关于产品使用原文的规定不变。
- 插图、音频、视频不在本目录保存。

## 三、待办

- 法务复核（0006）：在目录正式用于核验前，由真人安排法务确认。复核结论记录在本文件末尾。
- 在复核完成前，各科只能按本决定保存已经采集的文字，不再扩大采集范围。
