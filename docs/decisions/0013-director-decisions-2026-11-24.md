# 0013 项目总监决定（2026-11-24）

- 状态：项目总监决定（依据项目说明：中事与大事由项目总监决定）
- 关联：#23、#25、#68、#150、0011、0012

## 一、hub 用户入口路由（中事）
- 决定：以契约为准。hub 学科卡片使用 `/<学科>/`（学科 Web 版子路径），整页跳转，不在 hub 内部路由到学科。
- `/subjects/:code` 仅作兼容入口，由 `_redirects` 或 hub 内部转跳到 `/<学科>/`。
- 理由：契约第 6 节已定稿，学科 Web 版独立构建、独立部署，子路径跳转最简单可靠。

## 二、学生登录接口（中事）
- 决定：排在 P3 之后再设计。P3 完成前，生产构建的 hub 只做内测，不对外开放。

## 三、#110 身份服务持久化转正式（中事）
- 决定：等 MySQL 8 集成测试（测试库，#92 / #112）就绪并附完整输出后再转正式。在此之前保持草稿，不合并。

## 四、服务间内网令牌部署约定（大事）
- 决定：采用由部署方注入的共享密钥（环境变量）。密钥不入仓库、不写入代码。校验在 P3 之前接入。
- 理由：内网服务间调用的最小可行方案，不引入额外依赖。
