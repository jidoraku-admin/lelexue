# 0001 后端语言选择 Java

- 状态：已确定
- 决定人：真人（issue #1 留言 7035776796 确认）
- 日期：2026-11-20
- 关联：#1、docs/architecture/report-v3.md 第 2 节 D4

## 背景
乐乐学需要支持大数据高并发，并与游戏化、题库、AI 网关等共享服务配合。需要在 Java 和 Go 之间选择后端语言。

## 选项
- Java 21 + Spring Boot 3：生态成熟，团队可招募的人员多，共享服务与学科服务的工程模式统一。
- Go：启动快、并发性能好，适合少量高性能服务，但团队经验和生态积累较少。

## 结论
后端统一使用 Java 21 + Spring Boot 3。Go 可作为个别高性能本地服务的备选，需单独写决定记录。

## 影响
- 所有学科服务和共享服务使用同一技术栈。
- 新的后端服务需沿用本决定的依赖和目录约定。
