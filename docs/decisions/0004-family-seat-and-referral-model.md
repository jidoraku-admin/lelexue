# 0004 母子账号席位与渠道激励模式（结构已确认；法务 C6 已通过，数值由后台设置）

- 状态：结构已由真人确认（2026-11-20）。法务 C6 结论为通过（2026-11-24，见 0006 §七、§七之二）。佣金比例、封顶由后台按公司会议决定文件设置，不写入本文件。上线启动仍需真人确认（付费相关，大事）。
- 关联：0003、#1、#7、#25

## 一、已确认的结构

1. **母账号**是付费与管理主体，可以是家庭、班级或培训机构，按席位计价。
2. **子账号**是学习主体，不单独付费，由母账号分配和管理。
3. **渠道或老师激励**按母账号下真实付费席位的一次性佣金计算。不因下级渠道而拿钱，不设入门费，不要求囤货。

## 二、设计红线（不可突破）

- 不设多层级分成，不以发展下线人数作为计酬依据。
- 不以入门费、进货款或必须购买才能成为渠道的方式参与。
- 分享只奖励真实注册与付费。奖励次数与上限由后台配置，不在规则中写死（2026-11-21 真人确认，取消"每个用户只计一次"）。
- 不诱导分享、不强制分享，符合微信小程序平台规则。
- 积分（粟米）只兑换学习或会员时长，不兑换现金。

## 三、未定事项（需真人或法务确认）

1. 佣金比例、封顶金额：由后台按公司会议决定文件设置（法务 C6 通过）。
2. 结算与发票：结算按月；发票线上申请、线下发送，后期接入发票系统（法务 C6 通过）。分账方式以公司会议决定文件为准。
3. 培训机构资质与双减政策：法务已书面确认，通过（书面依据存公司档案）。
4. 未成年人子账号监护同意与数据最小化收集：法务通过。推送规则仍需产品在上线前明确。
5. 截图中"联合会员"的代理规则：法务回复为符合上述红线。

## 四、对项目的影响

- 设计师：联合会员与子账号的产品流程按本决定修订，佣金数值留空。
- 架构师：账号模型需支持母子关系与席位数，渠道佣金按真实付费事件计算，不存在层级递归。
- 运营：渠道推广只使用上述合规规则，不设发展下线的指标。
