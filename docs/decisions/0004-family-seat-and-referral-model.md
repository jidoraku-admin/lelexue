# 0004 母子账号席位与渠道激励模式（设计方向已由真人确认，数值待定）

- 状态：结构已由真人确认（2026-11-20）；佣金比例、封顶、结算方式待真人与法务确认
- 关联：0003、#1、#7、#25

## 一、已确认的结构

1. **母账号**是付费与管理主体，可以是家庭、班级或培训机构，按席位计价。
2. **子账号**是学习主体，不单独付费，由母账号分配和管理。
3. **渠道或老师激励**按母账号下真实付费席位的一次性佣金计算。不因下级渠道而拿钱，不设入门费，不要求囤货。

## 二、设计红线（不可突破）

- 不设多层级分成，不以发展下线人数作为计酬依据。
- 不以入门费、进货款或必须购买才能成为渠道的方式参与。
- 分享只奖励真实注册与付费，每个用户只计一次，设上限。
- 不诱导分享、不强制分享，符合微信小程序平台规则。
- 积分（粟米）只兑换学习或会员时长，不兑换现金。

## 三、未定事项（需真人或法务确认）

1. 佣金比例、封顶金额和结算周期。
2. 结算与发票流程，分账方式由法务确认。
3. 培训机构场景的资质与备案：学科类校外培训需先核对双减政策要求。
4. 未成年人子账号的监护同意、数据最小化收集与推送规则，由法务与产品一并确认。
5. 截图中"联合会员"的代理规则是否符合上述红线，需对照其实际条款复核。

## 四、对项目的影响

- 设计师：联合会员与子账号的产品流程按本决定修订，佣金数值留空。
- 架构师：账号模型需支持母子关系与席位数，渠道佣金按真实付费事件计算，不存在层级递归。
- 运营：渠道推广只使用上述合规规则，不设发展下线的指标。

## 补充决定（真人确认，2026-11-20）
- 佣金的推荐人范围：仅限营销人员。老师不作为佣金推荐人，班级开通保持免费，不计佣金。
- 营销人员的佣金仍按真实付费一次性结算，不设下级，不设入门费（红线同上）。
- 营销人员佣金的合规性（推广与佣金规定）仍为上线前的阻断项，由法务确认。
