# 0008 取消技术总监角色（2026-11-22）

- 决定人：真人（2026-11-22 确认）
- 分级：大事（团队结构），由真人确认
- 关联：#68（六对话协调）、0007（物理、化学学段）

## 决定

1. 取消"技术总监"角色。当前技术总监与项目总监由同一个对话承担，两个角色名称重复，职责边界模糊。
2. 技术总监的全部职责并入项目总监：统筹全项目、审核学科对话的设计结论（四个维度）与 PR、合并 PR、中事决定、每日汇总、审核架构方向与报告文件（含 `docs/architecture/report-v3.md`）。
3. 由此，"技术总监"在规则中的所有出现都理解为"项目总监"。

## 影响

- 规则文件已改：`docs/collaboration.md`、`docs/ownership.md`、`README.md`、`.github/` 下的 PR 模板与决定模板、`docs/automation/role-event-loop.md`、`docs/architecture/overview.md`，以及产品文档的状态行（"待项目总监审核"）。
- 历史决定记录（`docs/decisions/0002`–`0007`）与产品文档的更新日志中的"技术总监"保持原文，不做改写。阅读时按本决定理解为"项目总监"。
- 项目说明（Project instructions）中已没有技术总监角色，无需修改。
- 自动化循环（`role-event-loop`）中的签名 `【技术总监｜学科｜issue号】` 改为 `【项目总监｜学科｜issue号】`。

## 不变

- 决定分级（小事、中事、大事）、阶段标签、签名格式、PR 合并规则不变。
- 大事仍由真人确认。
